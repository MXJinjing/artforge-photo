# 隐私政策配置与首次启动验收

当前应用使用自有网站政策和应用内首启提示，已替代此前的华为隐私声明托管方案。

## 上架配置

在待发布版本的隐私政策配置中使用自定义 URL：

https://www.a999.cloud/statics/artforge-photo-privacy-policy.html

应用不再查询 `privacyManager`，也不订阅托管签署事件；`module.json5` 已移除 `appgallery_privacy_hosted` 等托管 metadata。不要为此版本同时启用托管首启提示。

网站政策、应用实际行为及上架填写内容应保持一致。剪贴板权限 `READ_PASTEBOARD` 的用途是用户主动粘贴图片或文字；打印、文件选择和持久化授权等信息也应如实说明。签名 Profile 中的剪贴板 ACL 仍需保留。

## 应用行为

- 首次启动显示放大的白色圆角隐私提示，居中展示应用图标和名称，提供“同意并继续”和“不同意并退出”。点击外部不关闭，也不视为同意。
- 点击《隐私政策》后，在同一弹窗中加载上述网站页面；阅读文章时隐藏同意和拒绝按钮，保留左侧“返回”和右侧“在浏览器中打开”；返回键或“返回”回到提示页后恢复两个按钮，阅读行为本身不记录同意。加载失败显示重试入口。
- 用户点击同意并成功保存政策版本后，才初始化原生编辑器、申请文档目录并启动打印等业务。
- 不同意或在提示页按返回键退出，下次启动仍需选择。
- 同意记录仅保存在设备本地；读取失败或写盘失败均不自动放行。
- 帮助菜单中的隐私政策及外部反馈链接继续使用系统浏览器。
- `PRIVACY_CONSENT_VERSION` 表示需征得同意的政策版本；涉及信息处理方式的更新须递增此值。

## 验收

在模拟器上以固定窗口尺寸保存首启提示、政策阅读页及同意后编辑器截图。

1. 全新安装或清除应用数据：启动出现提示，编辑器未初始化。
2. 点击《隐私政策》：网站内容出现在弹窗内；返回仍显示选择按钮，未自动同意。
3. 断网打开政策：显示加载失败和重试，联网后重试可恢复。
4. 点击不同意：退出；再次启动仍提示。点击遮罩或返回阅读页不能跳过。
5. 点击同意：进入编辑器；重启不再提示。
6. 清除应用数据或改变政策版本：再次提示。
7. 确认文件打开、保存/另存为及帮助菜单浏览器入口正常。

逻辑回归：`node scripts/test_privacy_consent.cjs <typescript 模块路径>`。
