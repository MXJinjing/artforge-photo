# 艺工坊·修图（ArtForge Photo）隐私政策

**更新日期：2026年10月20日**  
**生效日期：2026年10月20日**

## 一、开发者与应用信息

- **开发者身份**：个人开发者（非企业）
- **开发者**：MXJinjing / wang.jinjing
- **应用中文名**：艺工坊·修图
- **应用英文名**：ArtForge Photo
- **应用包名（bundleName）**：`wang.jinjing.artforge.photo`
- **适用范围**：本政策仅适用于上述 HarmonyOS 应用（当前分发设备类型为平板、PC/2in1）

本应用面向个人用户提供**本地、离线为主**的图片编辑能力。开发者未设立公司主体；本政策中的「我们」均指上述个人开发者。

## 二、我们如何收集和使用信息

### 2.1 基本原则

本应用以**设备本地处理**图像为主，**不要求注册账号**，**不运营用户云同步服务**，当前版本**未集成统计分析 SDK、广告 SDK、推送 SDK 或第三方账号登录 SDK**。

我们遵循合法、正当、必要和诚信原则，仅在实现产品功能所必需的范围内处理与功能直接相关的数据。

### 2.2 本应用不主动收集的信息

在当前版本中，我们**不收集**以下信息（除非未来功能变更并另行更新本政策并征得您的同意）：

| 类型 | 说明 |
|------|------|
| 账号信息 | 无注册/登录，不收集姓名、手机号、邮箱账号体系信息 |
| 设备标识 | 不收集 IMEI、IMSI、OAID、MAC、SN、Android ID 等用于追踪的设备标识 |
| 精确/粗略位置 | 不申请、不使用位置权限 |
| 通讯录 / 通话记录 / 短信 | 不申请、不使用相关权限 |
| 日历 / 传感器（非编辑必需） | 不用于画像或营销 |
| 应用列表 | 不读取已安装应用列表 |
| 剪贴板（非您主动粘贴场景） | 不在后台静默读取剪贴板用于画像 |

### 2.3 为实现核心功能而在本地处理的数据

以下数据通常**仅在您的设备本地**由您主动操作产生或选择，**不会由本应用自动上传至开发者服务器**（本应用当前亦未运营自有业务后端用于收集个人画像）：

1. **您选择打开或导入的图片 / 工程文件**  
   - 目的：完成查看、编辑、图层处理、导出等核心功能  
   - 方式：您通过系统文件选择器、图库选择器、拖放或「打开方式」主动选择  
   - 范围：您选定的文件内容及其编辑过程中的临时缓存、撤销记录等

2. **您主动保存或导出的文件**  
   - 目的：将编辑结果写入您指定或系统授权的目录  
   - 方式：系统文档选择器 / 应用文档目录等，由您确认

3. **应用运行所需的本地配置与缓存**  
   - 目的：记住界面偏好、保障编辑性能与稳定性  
   - 存储位置：应用沙箱（如 files / cache 等）  
   - 说明：属应用运行数据，一般不构成用于识别个人身份的画像信息

### 2.4 可能涉及网络的情形

`module.json5` 中声明了 `ohos.permission.INTERNET`。当前产品定位为离线编辑；网络能力主要用于（如发生）：打开您点击的外部链接、系统能力调用等，**不用于静默上报个人画像或行为分析**。若后续增加必须联网的功能，我们将更新本政策并依法征得同意。

### 2.5 敏感个人信息

您导入的照片可能包含人脸等敏感信息。此类内容由您主动提供并在本地编辑；我们不会将其用于营销或与身份识别无关的目的。请您仅导入您有权处理的内容。

## 三、设备权限说明

应用声明的权限及用途如下（与软件包配置保持一致）：

| 权限 | 用途 | 申请/使用时机 |
|------|------|----------------|
| `ohos.permission.PRINT` | 将您当前编辑结果送至系统打印服务 | 您主动发起打印时 |
| `ohos.permission.INTERNET` | 支持打开外部链接等联网能力（非静默分析） | 相关功能被触发时 |

**图片访问说明**：打开图库或文件时，通过系统提供的 **PhotoViewPicker / DocumentViewPicker** 等由您点选授权，**不在后台批量读取相册**。您拒绝授权仅影响对应导入/保存路径，不影响应用其他已具备条件的本地功能（在技术可行范围内）。

## 四、第三方 SDK 与共享

- **第三方 SDK**：当前版本**未接入**需向最终用户披露的统计分析、广告、推送、社交登录等第三方 SDK。  
- **与第三方共享**：我们**不向第三方出售**个人信息；当前亦无面向广告主或数据经纪人的共享。  
- 若系统打印、文件选择等由**操作系统或华为系统服务**完成，相关处理遵循系统与华为隐私规则，不由本应用另行上传至开发者服务器。

若未来接入第三方 SDK，我们将在本政策及华为应用市场隐私声明中逐一列明名称、主体、目的、信息种类与隐私链接，并依法取得同意。

## 五、信息存储地点与期限

- **存储地点**：默认仅存储于您的设备本地（应用沙箱及您授权的文件位置）。开发者不以自有云端业务数据库长期集中存储您的编辑图片。  
- **存储期限**：以实现编辑、导出等处理目的所必要的最短时间为限；您卸载应用或清除应用数据后，沙箱内数据将按系统规则删除。您自行保存到公共目录/图库的文件由您管理。

## 六、对未成年人的保护

本应用功能面向一般图像编辑，**不专门面向不满 14 周岁的儿童**。我们不会主动收集儿童个人信息。若您是监护人并发现儿童在未经同意的情况下使用了本应用，请通过下文联系方式与我们联系，我们将协助处理。

## 七、您的权利

在适用法律允许的范围内，您可以：

1. **知情与决定**：通过本政策与应用内入口了解处理规则；不同意时可停止使用并卸载应用。  
2. **查阅、复制、删除**：对仅存于设备本地的编辑文件与缓存，您可通过系统文件管理、应用存储清理或卸载进行删除。  
3. **撤回同意**：若您通过华为应用市场标准化隐私弹窗同意了隐私政策，可按系统/应用市场提供的方式管理同意状态；撤回不影响撤回前基于同意已进行的处理。  
4. **投诉与反馈**：见下文联系方式。

因本应用无账号体系，不适用「在线注销账号」流程；停止使用并卸载即可结束对本应用的使用。
