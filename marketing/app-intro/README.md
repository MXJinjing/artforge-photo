# 艺工坊·修图 · 动态创意版介绍视频

- 成片：`artforge-photo-intro-1920x1280.mp4`
- 规格：1920 × 1280，30 fps，34 秒；H.264 / AAC，原创合成背景音乐，无口播。
- HTML：`index.html`，图片已嵌入，可离线播放。鼠标移入显示暂停、重播和进度条；空格暂停。HTML 为静音预览，视频带音乐。
- 旧版保留为 `index-v1.html`、`intro-v1.template.html` 和 `artforge-photo-intro-v1-1920x1280.mp4`。

四角固定图标、品牌字样、平台文案与页码已移除；主体动画和底部细进度线保留。

## 新版分镜

| 时间 | 动作 |
| --- | --- |
| 0–4 秒 | 彩色形状旋转聚合，花瓣围绕应用图标展开，灵感标签漂浮 |
| 4–9 秒 | 原创山景拆成四层透视卡片，图层选择轮换，再合成为画面 |
| 9–14 秒 | 曲线控制点与游标移动，冷暖分界扫过原创山景 |
| 14–19 秒 | 画笔沿彩色曲线绘制，笔触由细变粗，再逐渐收笔；彩色粒子跟随笔尖 |
| 19–23 秒 | 公开资料卡片、扫描观察画面、转动的编辑逻辑齿轮 |
| 23–29 秒 | 六个模块从散开运动汇聚到编辑引擎，外框与就绪标签显现，更新流动画说明持续追踪上游、跟进新功能与鸿蒙适配 |
| 29–34 秒 | 实机首页出现，创作标签与星形围绕应用漂浮 |

功能场景为 HTML Canvas 原创动态图形，已标注“功能创意演绎”；实机截图在片尾展示。所有动作均由时间轴计算，可精确暂停与逐帧导出。

## 文案依据

“净室开发”归于上游 PhotoCraft，依据仓库内上游 `README.md` 的 Under the hood、`docs/contributing.md` 和 `docs/architecture.md`。区分上游开源引擎与本应用的 HarmonyOS 原生适配，未宣称全部功能等价或本应用全部开源；未出现用户要求避开的两个品牌名。

图标来自本应用资源，片尾实机截图由用户提供。原创矢量山景、粒子、花瓣、画笔、文档、齿轮均以 Canvas 路径直接绘制，无外部图库依赖。配乐由 `music.py` 独立合成：已恢复最初的轻柔氛围配乐。欢快版另存为 `music-upbeat.py` 和 `music-upbeat.wav`。开场花瓣采用 12 等分环形排列，完整覆盖一圈。

## 编辑与导出

编辑 `intro.template.html` 后运行 `python3 build.py`，再运行 `node render.cjs`。前者需安装 NumPy，并使用原附件临时路径，附件移走后需更新 `ASSETS`；现成的 `index.html` 已嵌入图片，无此限制。

导出依赖本机 Chromium、Playwright 与 FFmpeg，路径见 `render.cjs`；`node render.cjs --preview` 生成分镜预览。替换 `music.wav` 可更换配乐。

本目录只包含宣传素材，不涉及应用运行时、签名或原生宿主构建。
